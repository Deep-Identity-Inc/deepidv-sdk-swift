# Security Policy

## Supported versions

Security fixes are released as a new patch version of the latest release.
Update to the latest version to receive them; older versions don't get
separate fixes.

| Version        | Supported |
| -------------- | --------- |
| Latest release | yes       |
| Older releases | no        |

## Reporting a vulnerability

**Please don't report security vulnerabilities through public GitHub issues,
discussions, or pull requests.**

Report them privately instead, by either:

- **Email:** [privacy@deepidv.com](mailto:privacy@deepidv.com)
- **GitHub:** the **Report a vulnerability** button on this repository's
  [Security tab](https://github.com/Deep-Identity-Inc/deepidv-sdk-swift/security)

Please include as much of the following as you can:

- The SDK version affected.
- A description of the issue and its impact - for example, what data could be
  exposed or which check could be bypassed.
- Steps to reproduce, or a proof of concept.
- Any suggested fix or mitigation.

## Scope

This policy covers the deepidv iOS SDK in this repository.
